“衣履净界”智能鞋衣净护系统是一款面向入户健康场景的一体化智能家居设 备。针对市场上现有鞋柜、衣柜产品在自动清理与流程一体化方面的不足，本作品 以动线式场景交互重构家庭健康入口，构建覆盖衣物、鞋履、随身物品三大污染载 体的入户消毒闭环。系统采用模块化设计，上层通过平面传动机械臂与衣物悬浮腔 体实现衣物的无接触悬浮消毒除尘，下层通过鞋履存换装置实现室内外鞋子的自动 化智能置换，并辅以循环风道完成鞋履消毒除湿与热能回收。作品深度融合 AI 视 觉识别技术，基于优化后的 kmodel 与 onnx 高效模型对衣物污渍与鞋履类型进行 检测，驱动机械臂定点除污与鞋履自动匹配，同时集成语音识别与串口屏双通道人 机交互，实现智能化、人性化、绿色化的入户净护体验。
